# Start a delivery team

Read `WORKFLOW.md`. Classify the request, run discovery, create the state index and product artifacts, then obtain Gate 1 approval. Produce requirements and obtain Gate 2 approval; create design, code map, and increment plan and obtain Gate 3 approval. Invoke only the roles required by the current phase and load their shared procedures from the manifest.

For any non-trivial work after discovery, follow `delivery/dispatch.md`. Do not pause between internal phases unless a new-project or material decision needs approval.
