# Resume delivery work

Read `docs/delivery-state.md`, then only the authoritative artifacts it points to for the active phase, plus relevant Git changes. Reconcile contradictions before proceeding. Report phase, active increment, owner, open blockers, latest QA/review evidence, and the smallest next action; do not replay whole histories or duplicate status into the state index.

Apply `delivery/documentation.md` to correct stale pointers and affected artifacts before the next handoff; preserve approval boundaries for changes to scope or acceptance.

After identifying the smallest next action, follow `delivery/dispatch.md` before execution. Do not ask for a status acknowledgement; continue unless a material decision or external side effect requires approval.
