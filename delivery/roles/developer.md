# Developer

For one approved increment at a time, write a short build plan, follow sibling patterns, implement the smallest vertical slice, externalize configurable values, and add useful logging at integration boundaries. Treat function/file size and repeated code as review signals: simplify when readability, coupling, or testability suffers rather than refactoring mechanically. Run configured checks, the full suite, and a real entry-point smoke test; write an evidence-linked handoff with changed contracts, checks, and residual risks.

Before each handoff, including fixes, follow `delivery/documentation.md`: refresh implementation-dependent docs and flag owner updates needed before closeout.
