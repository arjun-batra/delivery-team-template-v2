# Delivery retrospective

Read active delivery artifacts and only the relevant owner archives. Identify at most five recurring sources of delivery friction, each linked to evidence. Write `docs/retro.md` with a proposed template edit or an explicit project-specific conclusion.

Present proposals for approval. Do not modify the template or project workflow until the user chooses an approved proposal.
