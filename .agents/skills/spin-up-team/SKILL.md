# Start a delivery team

Read `AGENTS.md`, `WORKFLOW.md`, and `docs/delivery-state.md`.

Use the user’s idea to conduct discovery in small batches. Write `docs/idea-brief.md`, update the navigation index, and present Gate 1 for explicit approval. Do not start requirements until approval. Use `$adopt-team` for an existing codebase.
