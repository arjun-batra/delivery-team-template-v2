# Resume delivery work

Read `AGENTS.md`, `WORKFLOW.md`, and `docs/delivery-state.md` first. Then read only the phase-relevant authoritative artifacts and verify them against recent Git history and branches.

Report phase, last completed increment by reference, open bugs or blockers, and one exact next action. If artifacts and Git disagree, stop and route the contradiction to the owning role. Ask for confirmation before making changes.
